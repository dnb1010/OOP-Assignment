# Tài liệu các bài tập OOP

Repository gồm các bài tập Python và Java minh họa những khái niệm lập trình hướng đối tượng từ nhập/xuất cơ bản đến kế thừa, đa hình, quản lý trạng thái và ngoại lệ.

## Danh mục

| Thư mục | Nội dung | Ngôn ngữ |
|---|---|---|
| [Bai 1](./Bai%201/README.md) | Nhập và in thông tin; tìm số lớn nhất trong ba số | Python |
| [Bai 2](./Bai%202/README.md) | Người, sinh viên, giảng viên và học phần | Python |
| [Bai 3](./Bai%203/README.md) | Đóng gói, thuộc tính, phương thức lớp/tĩnh và hình học | Python |
| [Bài 3](./B%C3%A0i%203/README.md) | Nhân sự dự án, kế thừa, đa hình và quản lý nhóm | Python |
| [Bài 4](./B%C3%A0i%204/README.md) | Tính lương theo loại nhân viên | Java |
| [Bài 6](./B%C3%A0i%206/README.md) | Quản lý phòng học, thiết bị, phiếu mượn và trả | Java |

> `Bai 3` và `Bài 3` là hai thư mục riêng: bài đầu chứa một tệp ví dụ Python, bài sau là ứng dụng quản lý nhân sự dự án.

## Ghi chú chung

- Tài liệu và lệnh chạy được viết cho mã nguồn trong `src/` hoặc các tệp `.py`; các thư mục `bin/`, `out/` và `__pycache__/` chỉ là đầu ra đã biên dịch/lưu đệm.
- Các chương trình mẫu chủ yếu chạy bằng console và không yêu cầu thư viện ngoài Python chuẩn hoặc JDK.
- Mỗi README con mô tả các lớp/hàm, quy tắc kiểm tra dữ liệu, luồng chạy và những giới hạn quan sát được trong mã.
